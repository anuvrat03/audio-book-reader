# Mobile Audiobook Reader

A simple, lightweight web app built to read documents out loud like an audiobook, designed to run smoothly on mobile devices.

## Features
- **Text-to-Speech:** Uses your phone's built-in voice system to read text out loud.
- **Play & Stop Controls:** Big, touch-friendly buttons to start or stop reading anytime.
- **Mobile Friendly:** Optimized for quick access on smartphone browsers.

## How to Use
1. Open the app link in your phone browser.
2. Paste or type your document text into the text area.
3. Tap **Play** to start listening, or **Stop** to end playback.
